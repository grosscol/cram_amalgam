# SV Approach
1. Subset SVs into non-overlapping sets
2. Pick single sample per variant
3. Take sequences from each sample
4. Compile each set into a cram

## Separation Distance
- Most sequence reads are ~200 bp
- SV boundaries determine the range requests

# IGV.js Scrolling
Current problem with the approach is that it can expose potentially confusing or misleading data.

- UI allows scrolling upstream/downstream
- Will reveal unrelated sequences

## JS Solution
- Use IGV's event `locuschange`
    > IGV provides a simple event system to listen for user interactions. Event handlers can be attached to the "Browser" object with the on function
- Guerilla patch IGV.js


## API Solution
Since the BRAVO API is providing the byte stream, it can be limited to a specific region.

- Bake in SV id into request to determine limits to data returned
